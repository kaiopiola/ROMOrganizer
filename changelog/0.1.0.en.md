# 0.1.0 — First release

_July 29, 2026_

ROMOrganizer is a desktop app that organizes the ROM collection you already have.
It identifies each file by its hash and renames it — instead of guessing from the
filename. Runs on macOS, Windows and Linux.

It never downloads, searches for or distributes game content. It works on files
that are already on your disk.

## Identification

Guessing a game from its filename is what makes other tools get it wrong. Here the
filename is the last resort, and you always see which one happened.

- Matches by hash against No-Intro and Redump DATs
- **Strips the header before hashing**, which is what makes a `.nes` carrying an
  iNES header or a `.smc` carrying an SMC header match at all — those DATs are
  headerless, so hashing the file raw never works
- Both variants are hashed in a single read, so it works whether your DAT includes
  the header or not
- Normalizes N64 byte order: `.v64` and `.n64` are recognized against a `.z64` DAT
- Reads ROMs inside `.zip` — usually **without decompressing anything**, since the
  zip format already stores the CRC32 of each entry
- When two DATs claim the same hash with different names, both show up and nothing
  is applied silently

## Databases

- libretro-database, downloaded on demand and cached
- Your own No-Intro or Redump DAT files, in either format they ship in
- Each console keeps its own choice — one can use libretro while another uses a
  local file you maintain

## Renaming

Nothing is written before you approve it.

- Every batch is a plan you review first, with the reason each file was left out:
  already correct, no name to propose, DATs disagree, name already taken, two files
  competing for the same name
- Pick line by line, or apply everything
- **Every batch can be undone.** The journal is written as it goes, so even a crash
  mid-batch leaves the undo intact
- Never overwrites and never deletes
- Naming pattern is yours to write: `{region}/{title}.{ext}` puts each game in a
  folder by region. It previews as you type, and the preview is produced by the same
  code that will do the work

## Audit

- What your collection has and what is missing, against the DAT
- Filter by region, which is what makes auditing a 1G1R set useful
- Prototypes and betas are out by default
- Finds duplicates and files no DAT recognizes
- Export to CSV or Markdown

## Playlists

- RetroArch playlist per platform, with the right database name so thumbnails work
- Multi-disc games are grouped into `.m3u` and appear as a single entry, not one
  line per disc
- Content inside zip is pointed to correctly

## Along the way

- Hashes are cached next to your collection, so a second scan doesn't re-read
  everything
- Queue several consoles and walk away — one job at a time, with progress and the
  reason for anything that failed
- Unidentified files can be moved aside to a folder of your choosing, never deleted
- English, Portuguese, or whatever your system uses

---

**Known limitation on macOS:** this build is not signed, so the app cannot install
its own updates there. It still tells you when a new version is out and takes you to
the download page. Windows and Linux update normally.
